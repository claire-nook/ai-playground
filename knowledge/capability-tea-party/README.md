# Capability Tea Party｜能力研究與可能性探索

> **Public research method / historical record.** 這個目錄保存探索新工具能力、重新檢驗舊限制，以及提出候選實驗的方法。它不負責私人 AI 啟動、跨對話提醒、個人授權或協作日程。

## Research Question

新的 Product Capability 是否可能組合成以前沒有的 Collaboration Capability？過去被判定不可行的方案，其阻礙條件是否已經改變？

**Provider defines Product Capability; researchers evaluate Collaboration Meaning.**

## Exploration Triggers

不以固定週期替代研究動機。值得重新檢查的訊號包括：

- Connector、Plugin、Agent Runtime 或 Workspace 的可觀察能力有實質變化。
- 某項工作仍需要大量人工搬運、複製、轉換或交接。
- 舊架構決策只是為了遷就當時的工具限制。
- 過去 `Not Feasible` 的失敗前提可能已改變。
- 新服務出現，即使沒有立即需求，也可能產生值得測試的組合能力。

**Elapsed time is a signal, not a schedule.** 研究日期、工具版本、權限及證據強度應明確記錄；舊判斷不能自動當成今日現況。

## Two Exploration Axes

### A. Human Bottleneck

哪些人工操作具有真正的判斷價值？哪些只是因工具、權限、Runtime 或檔案傳輸邊界而產生的 middleware？改善後能減少多少重複操作？

### B. New Capability / New Possibility

遇到新的服務或 Agent surface，可以逐項檢查：

```text
Read / Observe
Write / Mutate
Execute
Persist State
Publish
Receive Events
Trigger Other Systems
Identity / Permission
Evidence Collection
```

可能的技術角色包括 Eyes、Ears、Hands、Legs、Memory、Runtime、Workspace、Publication Surface 與 Bridge。這些是研究分類，不是宣稱任何特定工具已具備這些能力。

## Failed Ideas Are Assets｜保留「卒」的死因

```text
Status: Not Feasible / Candidate / Verified
Evaluated At: YYYY-MM-DD
Tested Surface: provider / tool / version / permissions
Killed By: 實際阻礙的 capability / permission / assumption
Revival Conditions: 哪些條件改變後值得重新測試
Evidence / References: experiment / provider / research record
```

曾探索的方向包括 Agent 之間的直接派工介面，以及持久、可供 AI 執行一般工作的 Workspace。當時不可行，不代表永久不可行；重新評估仍須有新證據。

## Research Record Convention

有實際討論或探索成果時，可以新增日期文件：

```text
YYYY-MM-DD.md
```

建議記錄 Date / Temporal Context、Observed Capabilities、Human Bottlenecks、Wild Ideas、Revisited Failed Ideas、Candidate Experiments、Conclusions 與 Revival Conditions。

討論不是驗證。Candidate 必須經過 Experiment／Evidence 才能升格為 Verified。

## Structured State as a Research Question

Markdown 適合保留可讀的研究脈絡；Database 適合查詢結構化關係。是否需要結構化資料庫，應由實際查詢、排序、狀態追蹤或關聯需求決定，而不是因為工具存在就啟動遷移。

## Core Principles

> 不要把今天 AI 的邊界，誤認成系統永久的邊界。

> 新服務代表新的研究可能性，不代表必須立即導入。

> 先確認可觀察能力與限制，再評估它能否帶來新的技術意義。
