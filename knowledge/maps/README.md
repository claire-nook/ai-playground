# Research Maps

Research Map 保存「我們為什麼沿著這條問題鏈研究、目前走到哪裡、還有哪些 Branch 值得繼續」，不是 Experiment 總目錄。

目前 Map：

- [`nook-technical-platform.md`](nook-technical-platform.md) — Nook Works Technical Platform capability / responsibility research。
- [`ai-agent-collaboration.md`](ai-agent-collaboration.md) — Human × Primary Agent × Implementation Agent collaboration、durable state、dispatch、workspace / credential boundary、adversarial review 與 future escalation。

同一個 Experiment 可以支援多張 Map；不要為了分類方便複製 Experiment Record 或 Evidence。畢竟知識圖譜的目的不是把同一篇東西影印三份，讓未來的人類猜哪份才是真的。
