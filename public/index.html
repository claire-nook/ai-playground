這裡不是正式開發環境，也不是永久 Demo 站。它是一張公開的實驗桌： 用真實 Browser、API、Database、Provider Runtime 去回答技術問題，再把 Experience / Evidence 留下來。

Gallery 只負責展示。 Experiment 的完整條件、限制與結論保存在 GitHub 的 Experiment Record / Evidence。 某個 Demo 日後失效，不代表當年的 Evidence 跟著蒸發。人類很愛把「網站還活著」誤認成「知識還存在」，這裡先阻止這件事。
